Live desktop

off

Copies one monitor, runs every new frame through neural rendering and shows the result in a click-through layer on top of it - everything underneath still works as normal. It adds a frame or two of delay, so it is for looking at things (videos, photos, the web, slower games), not for competitive play.

Monitor
The monitor to cover. Only monitors on the NVIDIA card can be used.
Frame cap
How often the desktop is re-rendered at most. Lower leaves more of the GPU for everything else.
Before / after split
Left half of the screen stays as it is, right half shows DLSS 5 - the quickest way to see what it changes. Ctrl+Alt+S switches it while running.

Ctrl+Alt+N hides and shows the effect, Ctrl+Alt+S splits before/after, Ctrl+Alt+End stops it. The look on the right and the frame cap change live while it runs (the monitor needs a restart). The default look is deliberately light - easy to miss without the split; Cinematic with 2-3 passes is the strongest. Anti-shimmer (under Video) works here too: it steadies moving pictures but adds about 8 ms of delay - off gives the snappiest desktop.

    Theme
    Dark suits a library of covers; light matches the rest of Windows.
    Fetch missing artwork from Steam
    Steam publishes library art for every game on an open CDN. Xbox and hand-added titles are looked up by name. Pictures are kept in the covers folder, so this happens once and works offline afterwards. No account, no key.
    Look for new versions when the app starts
    Asks the official GitHub page (github.com/revingale32/dlss5-aio-installer) for the newest version number and offers the update when there is one - nothing installs until you press Update and Restart. Nothing else is sent.
    Allow an unvalidated neural runtime
    Off, installs are refused when nvngx_dlssnr.dll is not the exact 310.8.0.0 file this build was validated with (its SHA-256 is checked). A modified or truncated copy makes NVIDIA's runtime refuse silently and there are tampered copies going around. Turn this on only if you know exactly where your file came from.

    version —

    Made by Revin (revingale32)

    Installs one renderer: the Standalone DLSS-NR + SR neural rendering add-on for ReShade, build —, into the games on this PC. Every file it touches is backed up first and verified by checksum; Restore originals puts a folder back exactly as it was found.

    What ships in the box

    DLSS 5 neural rendering add-onApache 2.0 - built from kibblerz's DLSS5-Reshade-AIO with our changes
    Neural relay (32-bit games)Written for this kit - neural-relay.exe and its launcher add-on, source in payload\relay\src
    OptiScaler NR (native-DLSS games)GPL-3.0 - wilsjo2's OptiScaler-DLSSNR-PreSR-Multipass fork; licence + SHA256SUMS in payload\optiscaler; ships no NVIDIA files
    ReShade 6.8 (add-on build, 64 + 32-bit)BSD 3-Clause - Patrick Mours and contributors, notice and licence in payload
    Media worker (pictures, videos, desktop)Apache 2.0 - written for this app, payload\media\dlss5-media.exe; optical flow code from the add-on
    NVIDIA runtime DLLsNot shipped - imported from your own PC

    Two rules

    Never bypass anti-cheat. EasyAntiCheat, BattlEye, Denuvo Anti-Cheat, Ricochet, GameGuard and Vanguard are detected and named, and the risk is spelled out before anything is written. Nothing here disables, patches or hides from any of them.

    Never destroy a file. Nothing is overwritten until a byte-for-byte copy exists on disk and verifies by SHA-256. If an install fails halfway, every file goes back; if the process dies mid-write, the next run finds the journal and repairs the folder before doing anything else.
